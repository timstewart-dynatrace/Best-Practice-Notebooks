Reading-Order Presets

Quick lists for time-boxed reading:

"I have 1 hour" — fastest orientation

  1. This document — sections Alphabetical Catalog and By Category
  2. README front door — pick a doorway based on your situation
  3. ONBRD — first 1–2 notebooks for orientation

"I have 1 week" — Foundation only

  1. ONBRD — full series (12 notebooks)
  2. ORGNZ — first 5 notebooks (introduction, buckets, bucket strategy, Grail permissions, bucket-level access)
  3. IAM — first 5 notebooks (governance, SSO, group architecture, policies, boundaries)

Aligned with Foundation Module.

"I have 1 month" — Foundation + first domain + light operationalize

  1. Foundation Module reading order
  2. One domain — typically K8S or CLOUD depending on environment
  3. DASH — first 4 notebooks (fundamentals, hierarchy, executive, operations)
  4. WFLOW — first 4 notebooks (fundamentals, triggers, notifications basics, notification routing)

"I have 1 quarter" — full Net New track

  1. Net New Doorway — full reading order across all phases
  2. Domain Enablement Module — at least 2 domains
  3. Operationalize Module — DASH → WFLOW → AUTOM
  4. Maturity Module — kick off

"I have 1 quarter" — Classic → Gen3 surface migration

  1. Classic → Gen3 Doorway — Phase 0 assessment, then Phase 1 in full
  2. MZ2POL — full series; ORGNZ — notebooks 02, 03, 05, 06, 08
  3. OPMIG — full series if still on Classic Logs (run as its own workstream)
  4. ALERT — full series before migrating any individual alert

Phases 2–5 typically extend past a quarter; the doorway sets the order.
