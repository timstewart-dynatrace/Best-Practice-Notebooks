APPSEC - Application Security

End-to-end application security observability with Dynatrace — covering Runtime Vulnerability Analytics, Runtime Application Protection, Security Posture Management, and the governance patterns to operationalize AppSec at scale.

Recommended: Import the JSON files from notebooks/ into a Dynatrace tenant for the best experience. These notebooks contain interactive DQL queries that execute against your environment's data.

Structure

Notebook Lineup

  1. Fundamentals and the Three Pillars of Application Security — RVA, RAP, and SPM architecture; the Gen3 Grail foundation for security findings
  2. Runtime Vulnerability Analytics — Third-party library CVE detection, exposure and vulnerable-function signals, and risk prioritization
  3. Code-Level Vulnerability Analytics — First-party vs. third-party detection, supported runtimes, entry point and code location, and process-group scoping
  4. Runtime Application Protection — Detection-to-blocking promotion, protection rules, and attack class coverage
  5. Security Posture Management — Compliance baseline evaluation (CIS, PCI, NIST) and misconfiguration findings
  6. Kubernetes and Container Security — Cross-pillar AppSec coverage for Kubernetes workloads and container images
  7. Investigations and Dynatrace Assist for Security — Evidence-driven investigation over Grail data and NL-to-DQL for security work
  8. Workflows, Notifications and Remediation — Routing findings to SOC, AppDev, and platform teams via Dynatrace Workflows
  9. IAM and Gen3 Permissions for AppSec — Permission catalog, persona policies, boundary patterns, and sensitive-data access controls
  10. Dashboards, Reporting and Governance — Executive dashboard composition, governance cadence, and FinOps angle for AppSec DPS billing
