# AGENTS.md — DTM: Dynatrace Managed

Per-series routing for AI agents. Repo-wide rules: [../AGENTS.md](../AGENTS.md).
Humans: see [README.md](README.md).

Reference notebooks on what is specific to a self-hosted **Dynatrace Managed**
cluster — **Dynatrace Classic only; none of it applies to SaaS**. Numbering is
banded: DTM-00 is the series map, 01–09 design and configure (cluster design,
cluster configuration, environments, ActiveGates, OneAgents), 10–19 operate a running cluster (node
architecture, a five-layer health model, one notebook per layer), and 99 is the
checklist. Best practices only — no installation walkthroughs.
Managed has no Grail, so the series contains **no DQL** and ships no importable
notebook JSON — markdown and PDF only.

For "what should I check / how often / which signals don't email" start with
DTM-99; for the detail behind any line, follow its pointer to DTM-10–16.
DTM-10–16 and DTM-99 were published as MCH-01–07 and MCH-99 (Managed Cluster
Health) until October 2026; DTM-00 §4 maps old IDs to new.
